# Sales Super Store Analysis using Excel

Welcome to the **Sales Super Store Analysis** project! This repository showcases how Excel can be leveraged to analyze and visualize retail sales data for strategic business insights. The project is ideal for those interested in data analysis, business intelligence, or Excel-based dashboards.

## 📊 Project Overview

This project involves analyzing sales data from a fictional Super Store to uncover trends, identify top-performing categories, monitor shipping costs, and gain insights that can drive better business decisions. The data has been transformed and visualized using Excel features such as:

* **Power Query** for data cleaning and preparation
* **Pivot Tables** for summarizing key metrics
* **Charts and Dashboards** for interactive data visualization

## 🗂️ Files Included

* `Sales Dataset.xlsx`: Raw sales data including order details, customer information, region, category, sales, profit, and more.
* `SalesPowerQuery.xlsx`: Processed data file with applied transformations using Power Query.
* `Shipping Cost.xlsx`: Supplementary data for analyzing shipping expenses in relation to profit and order types.

## 🧰 Tools Used

* Microsoft Excel

  * Power Query
  * Pivot Tables
  * Charts (Bar, Line, Pie, etc.)
  * Slicers and Filters

## 🚀 How to Use

1. Clone or download the repository.
2. Open the Excel files in Microsoft Excel.
3. Navigate to the dashboards or use slicers/filters to interact with the data.
4. Modify or extend the analysis using your own datasets or business questions.
